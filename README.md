# CRCE Placement Cell

Node.js version of the CRCE Placement Cell site.

## Run Locally

```bash
npm start
```

Then open:

- `http://localhost:3000/`
- `http://localhost:3000/login`
- `http://localhost:3000/student-portal`

No npm packages are required. The server uses Node's built-in `http` module and serves the frontend from `public/`.
